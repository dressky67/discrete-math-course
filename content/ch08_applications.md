## 8.2. Матрицы в теории графов

### 8.2.1. Степени матрицы смежности и подсчет путей

Пусть $G = (V, E)$ — граф с вершинами $\{v_1, v_2, \dots, v_n\}$ и матрицей смежности $A = (a_{ij})_{n \times n}$, где $a_{ij} = 1$, если есть ребро $(v_i, v_j)$, и $0$ в противном случае.

> **Теорема 8.1 (О степенях матрицы смежности).**  
> Число различных маршрутов длины $k \ge 1$ из вершины $v_i$ в вершину $v_j$ в графе $G$ в точности равно элементу $(i, j)$ матрицы $A^k$ ($k$-й степени матрицы смежности):
> $$N_k(v_i, v_j) = (A^k)_{ij}$$

*Доказательство (по математической индукции):*
- **База индукции ($k = 1$):** маршрут длины 1 — это одно ребро. Число таких маршрутов равно $a_{ij} = (A^1)_{ij}$. База верна.
- **Индукционный переход:** пусть утверждение верно для некоторого $k \ge 1$: $(A^k)_{im}$ равно числу путей длины $k$ из $v_i$ в $v_m$.  
  Любой маршрут длины $k + 1$ из $v_i$ в $v_j$ состоит из маршрута длины $k$ из $v_i$ в некоторую промежуточную вершину $v_m$ и одного шага из $v_m$ в $v_j$ (ребро с весом $a_{mj}$). По правилу умножения и сложения общее число таких маршрутов:
  $$N_{k+1}(v_i, v_j) = \sum_{m=1}^n N_k(v_i, v_m) \cdot a_{mj} = \sum_{m=1}^n (A^k)_{im} a_{mj} = (A^k \cdot A)_{ij} = (A^{k+1})_{ij}$$
  Переход доказан. $\blacksquare$

> **Следствие 8.1 (Число треугольников в графе).**  
> Диагональный элемент $(A^3)_{ii}$ равен числу замкнутых маршрутов длины 3, начинающихся и заканчивающихся в вершине $v_i$. В простом графе каждый такой маршрут является треугольником. Поскольку каждый треугольник обходится в двух направлениях и имеет 3 вершины, общее число треугольников в графе равно:
> $$N_{\triangle} = \frac{1}{6} \operatorname{tr}(A^3) = \frac{1}{6} \sum_{i=1}^n \lambda_i^3$$
> где $\lambda_i$ — собственные значения матрицы смежности $A$!

### 8.2.2. Матрица Лапласа и матричная теорема Кирхгофа о деревьях

Пусть $D = \operatorname{diag}(\deg(v_1), \dots, \deg(v_n))$ — диагональная матрица степеней вершин графа $G$.

> **Определение 8.1 (Матрица Лапласа графа).**  
> **Матрицей Лапласа (лапласианом)** графа $G$ называется матрица:
> $$L = D - A$$
> Элементы матрицы Лапласа:
> $$L_{ij} = \begin{cases} \deg(v_i), & \text{если } i = j, \\ -1, & \text{если } i \neq j \text{ и } (v_i, v_j) \in E, \\ 0, & \text{иначе.} \end{cases}$$

Свойства матрицы Лапласа:
1. Сумма элементов в каждой строке и каждом столбце равна нулю ($\sum_j L_{ij} = 0$), поэтому вектор $\mathbf{1} = (1, 1, \dots, 1)^T$ является собственным вектором с собственным значением $\lambda_1 = 0$: $L \mathbf{1} = \mathbf{0}$;
2. Матрица $L$ симметрична и положительно полу Patrickопределена ($L \ge 0$, все $\lambda_i \ge 0$);
3. Кратность собственного значения $0$ в точности равна **количеству компонент связности графа**. Граф связен $\iff \lambda_2 > 0$ (второе наименьшее собственное значение $\lambda_2$ называется *алгебраической связностью* или *числом Фидлера*).

> **Теорема 8.2 (Матричная теорема Кирхгофа о деревьях, 1847).**  
> Пусть $G$ — связный неориентированный граф с матрицей Лапласа $L$.  
> Все алгебраические дополнения элементов матрицы Лапласа равны между собой, и их общее значение в точности равно **количеству остовных деревьев $\tau(G)$** графа:
> $$\tau(G) = C_{ij} = (-1)^{i+j} M_{ij}(L) \quad (\text{для любых } i, j)$$
> В спектральной форме:
> $$\tau(G) = \frac{1}{n} \lambda_2 \lambda_3 \dots \lambda_n$$

## 8.3. Дискретные марковские цепи

### 8.3.1. Марковское свойство и матрица перехода

Пусть система в каждый дискретный момент времени $t = 0, 1, 2, \dots$ находится в одном из конечного числа состояний $S = \{1, 2, \dots, n\}$.

> **Определение 8.2 (Марковская цепь).**  
> Случайный процесс $\{X_t\}_{t=0}^\infty$ со значениями в $S$ называется **дискретной марковской цепью**, если выполняется **марковское свойство (отсутствие последействия)**: условная вероятность перехода в будущее состояние зависит только от текущего состояния и не зависит от всей предыстории процесса:
> $$P(X_{t+1} = j \mid X_t = i, X_{t-1} = i_{t-1}, \dots, X_0 = i_0) = P(X_{t+1} = j \mid X_t = i) = p_{ij}$$

Вероятности $p_{ij}$ называются **вероятностями перехода** из состояния $i$ в состояние $j$ за один шаг.

> **Определение 8.3 (Стохастическая матрица перехода).**  
> Матрица $P = (p_{ij})_{n \times n}$ называется **переходной матрицей** марковской цепи. Она удовлетворяет условиям:
> 1. Все элементы неотрицательны: $p_{ij} \ge 0$;
> 2. Сумма вероятностей перехода из каждого состояния по всем возможным исходам равна 1 (сумма элементов в каждой строке равна 1):
>    $$\sum_{j=1}^n p_{ij} = 1 \quad \forall i = 1, \dots, n$$
> Матрица с такими свойствами называется **стохастической (марковской)**.

### 8.3.2. Эволюция вероятностей и уравнение Чепмена–Колмогорова

Пусть $p^{(t)} = (p_1^{(t)}, p_2^{(t)}, \dots, p_n^{(t)})$ — вектор-строка распределения вероятностей на шаге $t$, где $p_i^{(t)} = P(X_t = i)$.

По формуле полной вероятности:
$$p^{(t+1)} = p^{(t)} P$$
По индукции распределение на шаге $n$ выражается через начальное распределение $p^{(0)}$ и $n$-ю степень матрицы перехода:
$$p^{(n)} = p^{(0)} P^n$$
Это соотношение выражает фундаментальное **уравнение Чепмена–Колмогорова**.

### 8.3.3. Стационарное распределение и эргодическая теорема

> **Определение 8.4 (Стационарное распределение).**  
> Вектор вероятностей $\pi = (\pi_1, \pi_2, \dots, \pi_n)$ называется **стационарным распределением** марковской цепи, если он не изменяется во времени при применении матрицы перехода:
> $$\pi P = \pi, \qquad \sum_{i=1}^n \pi_i = 1, \quad \pi_i \ge 0$$

В матричных терминах: стационарный вектор $\pi$ — это **левый собственный вектор** матрицы $P$, отвечающий собственному значению $\lambda = 1$ (или собственный вектор матрицы $P^T$):
$$(P^T - I) \pi^T = \mathbf{0}$$

> **Теорема 8.3 (Эргодическая теорема для регулярных цепей).**  
> Марковская цепь называется **регулярной (эргодической)**, если некоторая степень ее матрицы перехода $P^k$ строго положительна (все элементы $> 0$).  
> Для любой регулярной марковской цепи:
> 1. Существует **единственное** строго положительное стационарное распределение $\pi > 0$;
> 2. При $n \to \infty$ распределение вероятностей $p^{(n)}$ стремится к $\pi$ независимо от начального состояния:
>    $$\lim_{n \to \infty} p^{(0)} P^n = \pi \quad \forall p^{(0)}$$
> 3. Степени матрицы перехода сходятся к матрице, все строки которой одинаковы и равны $\pi$:
>    $$\lim_{n \to \infty} P^n = \begin{pmatrix} \text{---} & \pi & \text{---} \\ \text{---} & \pi & \text{---} \\ & \vdots & \\ \text{---} & \pi & \text{---} \end{pmatrix}$$

### 8.3.4. Применение: алгоритм Google PageRank

В 1998 году Ларри Пейдж и Сергей Брин разработали алгоритм ранжирования веб-страниц PageRank, смоделировав поведение пользователя интернета («случайного серфера»):
1. С вероятностью $d \approx 0.85$ (damping factor) серфер переходит по случайной гиперссылке с текущей страницы;
2. С вероятностью $1 - d \approx 0.15$ серфер «телепортируется» на случайно выбранную страницу интернета.

Это порождает регулярную стохастическую матрицу перехода Google:
$$G = d \cdot P + \frac{1 - d}{N} \mathbf{E}$$
Важность веб-страницы $i$ определяется как стационарная вероятность нахождения на ней: $\pi_i = (\text{PageRank})_i$. Google находит этот вектор методом степенных итераций ($\pi_{k+1} = \pi_k G$) для матрицы с миллиардами страниц!

## 8.4. Матричные преобразования в компьютерной графике

В 2D и 3D компьютерной графике каждый объект (персонаж, здание, автомобиль) задается набором вершин (координат в пространстве), соединенных треугольными полигонами. Перемещение камеры и движение объектов осуществляются с помощью матричных умножений.

### 8.4.1. Линейные преобразования плоскости $\mathbb{R}^2$

1. **Масштабирование (Scaling):**
   $$S(s_x, s_y) = \begin{pmatrix} s_x & 0 \\ 0 & s_y \end{pmatrix}, \qquad \begin{pmatrix} x' \\ y' \end{pmatrix} = \begin{pmatrix} s_x & 0 \\ 0 & s_y \end{pmatrix} \begin{pmatrix} x \\ y \end{pmatrix} = \begin{pmatrix} s_x x \\ s_y y \end{pmatrix}$$
2. **Вращение вокруг начала координат на угол $\theta$ (Rotation):**
   $$R(\theta) = \begin{pmatrix} \cos\theta & -\sin\theta \\ \sin\theta & \cos\theta \end{pmatrix}$$
3. **Сдвиг (Shear):**
   $$\text{Shear}_x(k) = \begin{pmatrix} 1 & k \\ 0 & 1 \end{pmatrix}, \qquad \text{Shear}_y(m) = \begin{pmatrix} 1 & 0 \\ m & 1 \end{pmatrix}$$

### 8.4.2. Парадокс переноса и однородные координаты

Операция **параллельного переноса (сдвига / translation)** на вектор $(t_x, t_y)$:
$$\begin{cases} x' = x + t_x \\ y' = y + t_y \end{cases}$$
**не является линейным преобразованием** в $\mathbb{R}^2$, поскольку начало координат смещается: $(0, 0) \to (t_x, t_y) \neq (0, 0)$. Невозможно подобрать матрицу $2 \times 2$, которая реализовывала бы перенос умножением!

#### Решение: Однородные координаты (August Möbius)
Добавим к вектору фиктивную третью координату $w = 1$:
$$(x, y) \in \mathbb{R}^2 \longleftrightarrow \begin{pmatrix} x \\ y \\ 1 \end{pmatrix} \in \mathbb{R}^3$$

Теперь параллельный перенос становится обычным линейным преобразованием в 3D!

> **Матрицы базовых 2D аффинных преобразований в однородных координатах:**
> - **Перенос (Translation):**
>   $$T(t_x, t_y) = \begin{pmatrix} 1 & 0 & t_x \\ 0 & 1 & t_y \\ 0 & 0 & 1 \end{pmatrix}$$
>   Проверка: $\begin{pmatrix} 1 & 0 & t_x \\ 0 & 1 & t_y \\ 0 & 0 & 1 \end{pmatrix} \begin{pmatrix} x \\ y \\ 1 \end{pmatrix} = \begin{pmatrix} x + t_x \\ y + t_y \\ 1 \end{pmatrix}$.
> - **Масштабирование:**
>   $$S(s_x, s_y) = \begin{pmatrix} s_x & 0 & 0 \\ 0 & s_y & 0 \\ 0 & 0 & 1 \end{pmatrix}$$
> - **Вращение вокруг начала координат:**
>   $$R(\theta) = \begin{pmatrix} \cos\theta & -\sin\theta & 0 \\ \sin\theta & \cos\theta & 0 \\ 0 & 0 & 1 \end{pmatrix}$$

### 8.4.3. Композиция преобразований

Благодаря ассоциативности матричного умножения любая последовательность трансформаций объединяется в **одну результирующую матрицу $3 \times 3$** (в 2D) или $4 \times 4$ (в 3D):
$$M = M_k \cdot M_{k-1} \dots M_2 \cdot M_1$$
После перемножения матриц трансформация тысяч вершин объекта требует всего одного матрично-векторного умножения на вершину!

*Поворот вокруг произвольной точки $(x_0, y_0)$:*
1. Переносим центр вращения $(x_0, y_0)$ в начало координат: $T(-x_0, -y_0)$;
2. Вращаем вокруг начала координат: $R(\theta)$;
3. Возвращаем центр обратно: $T(x_0, y_0)$.  
Результирующая матрица:
$$M = T(x_0, y_0) \cdot R(\theta) \cdot T(-x_0, -y_0)$$

## 8.5. Подробно разобранные примеры

### Пример 8.1. Маршруты и остовные деревья через матрицы графа

**Условие:**  
Дан граф в виде треугольника с висячей вершиной: вершины $\{1, 2, 3, 4\}$, рёбра: $(1, 2), (2, 3), (1, 3), (3, 4)$.
1. Записать матрицу смежности $A$ и найти число маршрутов длины 3 между вершиной 1 и вершиной 2.
2. Построить матрицу Лапласа $L$ и вычислить количество остовных деревьев графа с помощью матричной теоремы Кирхгофа.

**Решение:**

1. **Матрица смежности $A$:**
   $$A = \begin{pmatrix} 0 & 1 & 1 & 0 \\ 1 & 0 & 1 & 0 \\ 1 & 1 & 0 & 1 \\ 0 & 0 & 1 & 0 \end{pmatrix}$$
   Вычислим $A^2$:
   $$A^2 = \begin{pmatrix} 0 & 1 & 1 & 0 \\ 1 & 0 & 1 & 0 \\ 1 & 1 & 0 & 1 \\ 0 & 0 & 1 & 0 \end{pmatrix} \begin{pmatrix} 0 & 1 & 1 & 0 \\ 1 & 0 & 1 & 0 \\ 1 & 1 & 0 & 1 \\ 0 & 0 & 1 & 0 \end{pmatrix} = \begin{pmatrix} 2 & 1 & 1 & 1 \\ 1 & 2 & 1 & 1 \\ 1 & 1 & 3 & 0 \\ 1 & 1 & 0 & 1 \end{pmatrix}$$
   Вычислим $A^3 = A^2 \cdot A$:
   $$(A^3)_{12} = \text{строка 1 матрицы } A^2 \times \text{столбец 2 матрицы } A = 2(1) + 1(0) + 1(1) + 1(0) = 2 + 1 = 3$$
   **Ответ:** Между вершинами 1 и 2 существует ровно 3 маршрута длины 3:
   - $1 \to 2 \to 1 \to 2$
   - $1 \to 3 \to 1 \to 2$
   - $1 \to 2 \to 3 \to 2$

2. **Матрица Лапласа $L$:**  
   Степени вершин: $\deg(1) = 2, \deg(2) = 2, \deg(3) = 3, \deg(4) = 1$.
   $$L = D - A = \begin{pmatrix} 2 & -1 & -1 & 0 \\ -1 & 2 & -1 & 0 \\ -1 & -1 & 3 & -1 \\ 0 & 0 & -1 & 1 \end{pmatrix}$$

   По теореме Кирхгофа число остовных деревьев равно алгебраическому дополнению любого элемента. Вычеркнем 4-ю строку и 4-й столбец (соответствующие висячей вершине 4):
   $$\tau(G) = C_{44} = (-1)^{4+4} \begin{vmatrix} 2 & -1 & -1 \\ -1 & 2 & -1 \\ -1 & -1 & 3 \end{vmatrix}$$
   Вычислим определитель $3 \times 3$:
   $$\det = 2(6 - 1) - (-1)(-3 - 1) + (-1)(1 - (-2)) = 2(5) + 1(-4) - 1(3) = 10 - 4 - 3 = 3$$

   **Ответ:** Граф имеет ровно 3 остовных дерева.  
   *Проверка:* чтобы дерево было связным, ребро $(3, 4)$ обязано входить в остов. В оставшемся треугольнике $\{1, 2, 3\}$ достаточно удалить любое одно из 3 рёбер, чтобы разрушить цикл. Это дает ровно $\binom{3}{1} = 3$ остовных дерева! Результат сошелся идеально.

### Пример 8.2. Моделирование марковской цепи и стационарное распределение

**Условие:**  
Пользователь интернет-магазина в каждый момент времени находится в одном из трех состояний:
- Состояние 1: Просмотр главной страницы (Home);
- Состояние 2: Просмотр каталога товаров (Catalog);
- Состояние 3: Оформление заказа в корзине (Cart).

Матрица перехода за один переход имеет вид:
$$P = \begin{pmatrix} 0.2 & 0.7 & 0.1 \\ 0.3 & 0.4 & 0.3 \\ 0.1 & 0.3 & 0.6 \end{pmatrix}$$
Найти вектор стационарного распределения $\pi = (\pi_1, \pi_2, \pi_3)$ и определить среднюю долю времени, которую активный покупатель проводит в корзине покупок.

**Решение:**  
Стационарный вектор удовлетворяет системе уравнений:
$$\pi P = \pi \iff \pi (P - I) = \mathbf{0}, \qquad \pi_1 + \pi_2 + \pi_3 = 1$$
Запишем матрицу $P - I$:
$$P - I = \begin{pmatrix} -0.8 & 0.7 & 0.1 \\ 0.3 & -0.6 & 0.3 \\ 0.1 & 0.3 & -0.4 \end{pmatrix}$$
Система в компонентах:
$$\begin{cases} -0.8\pi_1 + 0.3\pi_2 + 0.1\pi_3 = 0 \\ 0.7\pi_1 - 0.6\pi_2 + 0.3\pi_3 = 0 \\ \pi_1 + \pi_2 + \pi_3 = 1 \end{cases}$$
(Третье уравнение из $P - I$ опускаем, так как строки $P - I$ линейно зависимы, и заменяем его условием нормировки).

Умножим первое уравнение на 10: $-8\pi_1 + 3\pi_2 + \pi_3 = 0 \implies \pi_3 = 8\pi_1 - 3\pi_2$.  
Подставим во второе уравнение:
$$0.7\pi_1 - 0.6\pi_2 + 0.3(8\pi_1 - 3\pi_2) = 0$$
$$0.7\pi_1 - 0.6\pi_2 + 2.4\pi_1 - 0.9\pi_2 = 0 \implies 3.1\pi_1 - 1.5\pi_2 = 0 \implies \pi_2 = \frac{31}{15} \pi_1$$
Выразим $\pi_3$:
$$\pi_3 = 8\pi_1 - 3\left(\frac{31}{15}\pi_1\right) = 8\pi_1 - \frac{31}{5}\pi_1 = \frac{40 - 31}{5}\pi_1 = \frac{9}{5}\pi_1 = \frac{27}{15}\pi_1$$
Подставим в условие нормировки:
$$\pi_1 + \frac{31}{15}\pi_1 + \frac{27}{15}\pi_1 = 1 \implies \frac{15 + 31 + 27}{15}\pi_1 = 1 \implies \frac{73}{15}\pi_1 = 1$$
$$\pi_1 = \frac{15}{73} \approx 0.2055 \quad (20.55\%)$$
$$\pi_2 = \frac{31}{73} \approx 0.4247 \quad (42.47\%)$$
$$\pi_3 = \frac{27}{73} \approx 0.3699 \quad (36.99\%)$$

**Ответ:** Стационарное распределение $\pi \approx (0.2055, \; 0.4247, \; 0.3699)$.  
В корзине покупатель проводит в среднем $\frac{27}{73} \approx 36.99\%$ времени.

### Пример 8.3. 2D трансформация в компьютерной графике

**Условие:**  
Треугольник с вершинами $A(1, 1)$, $B(3, 1)$, $C(2, 3)$ подвергается следующему сложному преобразованию:
1. Поворот на $90^\circ$ против часовой стрелки вокруг точки $P_0(1, 2)$;
2. Последующий перенос на вектор $(3, -2)$.  
Найти единую матрицу преобразования $3 \times 3$ в однородных координатах и новые координаты вершин треугольника.

**Решение:**

Матрица поворота вокруг точки $(1, 2)$:
$$M_{\text{rot}} = T(1, 2) \cdot R(90^\circ) \cdot T(-1, -2)$$
Матрицы компонент:
$$T(1, 2) = \begin{pmatrix} 1 & 0 & 1 \\ 0 & 1 & 2 \\ 0 & 0 & 1 \end{pmatrix}, \quad R(90^\circ) = \begin{pmatrix} 0 & -1 & 0 \\ 1 & 0 & 0 \\ 0 & 0 & 1 \end{pmatrix}, \quad T(-1, -2) = \begin{pmatrix} 1 & 0 & -1 \\ 0 & 1 & -2 \\ 0 & 0 & 1 \end{pmatrix}$$
Перемножим:
$$R(90^\circ) \cdot T(-1, -2) = \begin{pmatrix} 0 & -1 & 2 \\ 1 & 0 & -1 \\ 0 & 0 & 1 \end{pmatrix}$$
$$M_{\text{rot}} = \begin{pmatrix} 1 & 0 & 1 \\ 0 & 1 & 2 \\ 0 & 0 & 1 \end{pmatrix} \begin{pmatrix} 0 & -1 & 2 \\ 1 & 0 & -1 \\ 0 & 0 & 1 \end{pmatrix} = \begin{pmatrix} 0 & -1 & 3 \\ 1 & 0 & 1 \\ 0 & 0 & 1 \end{pmatrix}$$

Теперь применим последующий перенос $T(3, -2)$:
$$M = T(3, -2) \cdot M_{\text{rot}} = \begin{pmatrix} 1 & 0 & 3 \\ 0 & 1 & -2 \\ 0 & 0 & 1 \end{pmatrix} \begin{pmatrix} 0 & -1 & 3 \\ 1 & 0 & 1 \\ 0 & 0 & 1 \end{pmatrix} = \begin{pmatrix} 0 & -1 & 6 \\ 1 & 0 & -1 \\ 0 & 0 & 1 \end{pmatrix}$$

Преобразуем координаты вершин:
- Вершина $A(1, 1, 1)^T$:
  $$\begin{pmatrix} 0 & -1 & 6 \\ 1 & 0 & -1 \\ 0 & 0 & 1 \end{pmatrix} \begin{pmatrix} 1 \\ 1 \\ 1 \end{pmatrix} = \begin{pmatrix} 5 \\ 0 \\ 1 \end{pmatrix} \implies A'(5, 0)$$
- Вершина $B(3, 1, 1)^T$:
  $$\begin{pmatrix} 0 & -1 & 6 \\ 1 & 0 & -1 \\ 0 & 0 & 1 \end{pmatrix} \begin{pmatrix} 3 \\ 1 \\ 1 \end{pmatrix} = \begin{pmatrix} 5 \\ 2 \\ 1 \end{pmatrix} \implies B'(5, 2)$$
- Вершина $C(2, 3, 1)^T$:
  $$\begin{pmatrix} 0 & -1 & 6 \\ 1 & 0 & -1 \\ 0 & 0 & 1 \end{pmatrix} \begin{pmatrix} 2 \\ 3 \\ 1 \end{pmatrix} = \begin{pmatrix} 3 \\ 1 \\ 1 \end{pmatrix} \implies C'(3, 1)$$

## 8.7. Полные решения задач

### Решение задачи 8.1
В $K_4$ матрица смежности имеет 0 на диагонали и 1 вне диагонали: $A = J - I$, где $J$ — матрица из всех единиц.  
Собственные значения $J$: $\{4, 0, 0, 0\}$.  
Следовательно, собственные значения $A$: $\lambda_1 = 4 - 1 = 3$, $\lambda_2 = \lambda_3 = \lambda_4 = 0 - 1 = -1$.  
Число маршрутов длины 4 из вершины 1 в саму себя равно элементу $(A^4)_{11}$.  
В силу симметрии все диагональные элементы $A^4$ одинаковы:
$$(A^4)_{11} = \frac{1}{4} \operatorname{tr}(A^4) = \frac{1}{4} \sum_{i=1}^4 \lambda_i^4 = \frac{1}{4} (3^4 + (-1)^4 + (-1)^4 + (-1)^4) = \frac{1}{4} (81 + 1 + 1 + 1) = \frac{84}{4} = 21$$

**Ответ:** 21 маршрут.

### Решение задачи 8.2
В $K_n$ каждая вершина соединена со всеми остальными $n - 1$ вершинами.  
Матрица Лапласа:
$$L = (n - 1)I - (J - I) = n I - J$$
Собственные значения $J$: $\{n, 0, 0, \dots, 0\}$ (кратность 0 равна $n - 1$).  
Следовательно, собственные значения $L$:
- $\lambda_1 = n - n = 0$
- $\lambda_2 = \lambda_3 = \dots = \lambda_n = n - 0 = n$ (все $n - 1$ оставшихся собственных значений равны $n$).  
По формуле Кирхгофа:
$$\tau(K_n) = \frac{1}{n} \prod_{i=2}^n \lambda_i = \frac{1}{n} \cdot n^{n-1} = n^{n-2}$$
Формула Кэли доказана спектральным методом. $\blacksquare$

### Решение задачи 8.3
1. Пусть $P, Q$ — стохастические матрицы: $p_{ij} \ge 0, q_{ij} \ge 0$, $\sum_j p_{ij} = 1, \sum_j q_{ij} = 1$.  
   Элементы произведения $(PQ)_{ij} = \sum_k p_{ik} q_{kj} \ge 0$.  
   Сумма по $j$-й строке:
   $$\sum_{j} (PQ)_{ij} = \sum_j \sum_k p_{ik} q_{kj} = \sum_k p_{ik} \underbrace{\left(\sum_j q_{kj}\right)}_{1} = \sum_k p_{ik} \cdot 1 = 1$$
   Следовательно, $PQ$ стохастична.
2. Так как $P \mathbf{1} = \mathbf{1}$, число $\lambda = 1$ всегда является собственным значением.  
   Пусть $P v = \lambda v$ и $|v_k| = \max_i |v_i| > 0$.  
   Тогда $|\lambda| |v_k| = |\sum_j p_{kj} v_j| \le \sum_j p_{kj} |v_j| \le |v_k| \sum_j p_{kj} = |v_k|$.  
   Разделив на $|v_k| > 0$, получаем $|\lambda| \le 1$.  
   Следовательно, $\rho(P) = 1$. $\blacksquare$

### Решение задачи 8.4
Состояния: $0, 1, 2, 3, 4$. Состояния 0 и 4 поглощающие ($p_{00} = 1, p_{44} = 1$).  
Пусть $u_i$ — вероятность разорения из состояния $i$.  
Уравнения марковского блуждания:
$$u_0 = 1, \quad u_4 = 0$$
$$u_i = 0.5 u_{i-1} + 0.5 u_{i+1} \implies u_i - u_{i-1} = u_{i+1} - u_i$$
Разности постоянны, то есть $u_i$ образует арифметическую прогрессию!  
$$u_i = 1 - \frac{i}{4}$$
Для начального капитала $i = 2$:
$$u_2 = 1 - \frac{2}{4} = 0.5$$

**Ответ:** Вероятность разорения равна $0.5$ (50%).

### Решение задачи 8.5
Система $\pi P = \pi$:
$$\begin{pmatrix} \pi_1 & \pi_2 \end{pmatrix} \begin{pmatrix} 1 - a & a \\ b & 1 - b \end{pmatrix} = \begin{pmatrix} \pi_1 & \pi_2 \end{pmatrix}$$
$$\pi_1(1 - a) + \pi_2 b = \pi_1 \implies -a \pi_1 + b \pi_2 = 0 \implies b \pi_2 = a \pi_1 \implies \pi_2 = \frac{a}{b} \pi_1$$
Нормировка $\pi_1 + \pi_2 = 1$:
$$\pi_1 \left(1 + \frac{a}{b}\right) = 1 \implies \pi_1 \left(\frac{a + b}{b}\right) = 1 \implies \pi_1 = \frac{b}{a + b}, \quad \pi_2 = \frac{a}{a + b}$$

### Решение задачи 8.7
Квадратичная форма матрицы Лапласа:
$$x^T L x = x^T (D - A) x = \sum_{i=1}^n \deg(v_i) x_i^2 - 2 \sum_{(i, j) \in E} x_i x_j = \sum_{(i, j) \in E} (x_i - x_j)^2$$
Так как сумма квадратов неотрицательна, $x^T L x = 0 \iff x_i = x_j$ для каждого ребра $(i, j) \in E$.  
Следовательно, вектор $x$ постоянен на каждой компоненте связности графа.  
Если граф имеет $k$ компонент связности $V_1, \dots, V_k$, то пространство решений $L x = \mathbf{0}$ имеет базис из $k$ характеристических векторов компонент: $\mathbf{1}_{V_1}, \dots, \mathbf{1}_{V_k}$.  
Размерность ядра равна $k$, то есть кратность нуля как собственного значения в точности равна $k$. $\blacksquare$

### Решение задачи 8.8
Из подобия треугольников луч из центра $(0, 0, 0)$ через точку $(x, y, z)$ пересекает плоскость $z = d$ в координатах:
$$x' = d \frac{x}{z}, \quad y' = d \frac{y}{z}$$
В однородных координатах вектор $(x', y', 1)^T$ представляется как $(d x, d y, z)^T$.  
Матрица $4 \times 4$:
$$P_{\text{persp}} = \begin{pmatrix} d & 0 & 0 & 0 \\ 0 & d & 0 & 0 \\ 0 & 0 & d & 0 \\ 0 & 0 & 1 & 0 \end{pmatrix}$$
Умножение на $(x, y, z, 1)^T$ дает $(dx, dy, dz, z)^T$. После перспективного деления на 4-ю координату $w = z$ получаем $(d \frac{x}{z}, d \frac{y}{z}, d, 1)^T$.

### Решение задачи 8.9
Граф ссылок:

### Решение задачи 8.10
Матрица Лапласа $L$ вещественна и симметрична. По теореме Куранта–Фишера собственные значения упорядочены $0 = \lambda_1 \le \lambda_2 \le \dots \le \lambda_n$.  
Собственный вектор для $\lambda_1 = 0$ — это $\mathbf{1} = (1, 1, \dots, 1)^T$.  
Второе собственное значение $\lambda_2$ минимизирует отношение Рэлея на ортогональном дополнении к первому собственному вектору ($x \perp \mathbf{1} \iff \sum x_i = 0$):
$$\lambda_2 = \min_{x \perp \mathbf{1}, x \neq \mathbf{0}} \frac{x^T L x}{x^T x} = \min_{\sum x_i = 0} \frac{\sum_{(u, v) \in E} (x_u - x_v)^2}{\sum_{u \in V} x_u^2} \quad \blacksquare$$
Вектор Фидлера $v_2$ делит граф на две плотные части по знаку компонент $x_i > 0$ и $x_i < 0$ (спектральная бисекция).
