Анализ 5 свойств отношения
Рефлексивность
∀ x (x R x) — все диагональные ячейки = 1
...
Антирефлексивность
∀ x (¬(x R x)) — все диагональные ячейки = 0
...
Симметричность
x R y ⇒ y R x — матрица симметрична относительно диагонали
...
Антисимметричность
(x R y ∧ y R x) ⇒ x = y — нет взаимных стрелок между разными вершинами
...
Транзитивность
(x R y ∧ y R z) ⇒ x R z — пути длины 2 замыкаются прямой стрелкой
