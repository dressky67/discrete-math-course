Проверка системы по критерию Поста

Система булевых функций полна тогда и только тогда, когда она не содержится целиком ни в одном из 5 замкнутых предполных классов: T₀, T₁, S, M, L.

Функция T₀ (сохр. 0) T₁ (сохр. 1) S (самодв.) M (монот.) L (линейн.)

Вердикт теоремы Поста

Справка по классам:

  • T₀: f(0, …, 0) = 0
  • T₁: f(1, …, 1) = 1
  • S: ¬f(x₁, …, xₙ) = f(¬x₁, …, ¬xₙ)
  • M: при α ≤ β ⟹ f(α) ≤ f(β)
  • L: полином Жегалкина не содержит конъюнкций (степень ≤ 1)
