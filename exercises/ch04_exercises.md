# Задачи и решения к Главе 4. Теория графов

Содержит 10 задач по нарастанию сложности:
- **Задача 4.1**: Критерии существования графов по последовательности степеней вершин
- **Задача 4.2**: Оценки на минимальное и максимальное число рёбер в графе с $k$ компонентами
- **Задача 4.3**: Критерий эйлеровости для полных $K_n$ и двудольных $K_{n, m}$ графов
- **Задача 4.4**: Формула Кэли $n^{n-2}$ и подсчет числа остовных деревьев для $n = 4$
- **Задача 4.5**: Алгоритм Краскала для построения минимального остова (MST)
- **Задача 4.6**: Критерий двудольности графа (отсутствие нечетных циклов)
- **Задача 4.7**: Вычисление числа граней плоского 3-регулярного графа по формуле Эйлера
- **Задача 4.8**: Хроматическое число графа-колеса $W_n$
- **Задача 4.9**: Топологическая сортировка DAG с помощью поиска в глубину (DFS)
- **Задача 4.10**: Доказательство непланарности графа Петерсена (Эйлер и Куратовский)
