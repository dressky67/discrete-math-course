# Задачи и решения к Главе 1. Логика высказываний и теория множеств

Содержит 10 задач по возрастанию сложности с полным пошаговым решением, доказательствами и разбором логических парадоксов.

## Список задач
- **Задача 1.1**: Таблица истинности для формулы $F(P, Q) = (P \lor \neg Q) \to (P \land Q)$
- **Задача 1.2**: Доказательство тавтологии Modus Ponens $((P \to Q) \land P) \to Q$
- **Задача 1.3**: Упрощение логического выражения $G(P, Q) = \neg(P \land \neg Q) \land (P \lor Q)$
- **Задача 1.4**: Операции над множествами $A = \{1, 2, 3, 4, 5\}$ и $B = \{3, 4, 5, 6, 7\}$
- **Задача 1.5**: Доказательство тождества декомпозиции $(A \cap B) \cup (A \cap \overline{B}) = A$
- **Задача 1.6**: Доказательство ассоциативности симметрической разности $(A \triangle B) \triangle C = A \triangle (B \triangle C)$
- **Задача 1.7**: Вычисление вложенных мощностей булеанов $\mathcal{P}(\mathcal{P}(\mathcal{P}(\emptyset)))$
- **Задача 1.8**: Тождество и мощность декартова произведения $(A \times B) \cap (A \times C) = A \times (B \cap C)$
- **Задача 1.9**: Логическая задача о рыцарях и лжецах (формализация и вывод)
- **Задача 1.10**: Вывод формулы мощности объединения $|A \cup B| = |A| + |B| - |A \cap B|$ через разбиение
