# Задачи и решения к Главе 5. Матрицы: операции, ранг и обратная матрица

Содержит 10 задач по нарастанию сложности:
- **Задача 5.1**: Линейные комбинации, некоммутативность умножения $AB \neq BA$
- **Задача 5.2**: Нильпотентные матрицы: степени матрицы $N$, $N^2, N^3, N^{100}$
- **Задача 5.3**: Разложение матрицы в сумму симметричной и кососимметричной $M = S + K$
- **Задача 5.4**: Элементарные преобразования строк, ступенчатый вид и ранг матрицы $4 \times 4$
- **Задача 5.5**: Исследование ранга матрицы с параметром $\lambda$
- **Задача 5.6**: Вывод и применение формулы обратной матрицы $2 \times 2$
- **Задача 5.7**: Пошаговое вычисление обратной матрицы $3 \times 3$ методом Гаусса-Жордана
- **Задача 5.8**: Решение двустороннего матричного уравнения $AXB = C$
- **Задача 5.9**: Алгебра проекторов (идемпотентных матриц $P^2 = P$)
- **Задача 5.10**: Доказательство неравенства Сильвестра для рангов $\operatorname{rank}(A) + \operatorname{rank}(B) - n \le \operatorname{rank}(AB)$
