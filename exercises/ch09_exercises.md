# Задачи и решения к Главе 9. Булевы функции, минимизация и теория чисел в криптографии

Содержит 10 задач по нарастанию сложности с полными решениями:
- **Задача 9.1**: Построение канонического полинома Жегалкина методом треугольника Паскаля по модулю 2
- **Задача 9.2**: Проверка функциональной полноты системы булевых функций по критерию Поста ($T_0, T_1, S, M, L$)
- **Задача 9.3**: Выражение всех базовых логических связок через единственный штрих Шеффера (NAND)
- **Задача 9.4**: Нахождение общего целочисленного решения линейного диофантова уравнения через расширенный алгоритм Евклида
- **Задача 9.5**: Решение системы линейных сравнений методом Китайской теоремы об остатках (КТО)
- **Задача 9.6**: Вычисление и аналитическое доказательство мультипликативности функции Эйлера $\varphi(n)$
- **Задача 9.7**: Вычисление сверхбольших степеней по модулю с помощью Малой теоремы Ферма и быстрого возведения в степень
- **Задача 9.8**: Анализ уязвимости криптосистемы RSA при малом секретном показателе (атака Винера)
- **Задача 9.9**: Минимизация булевой функции 4 переменных методом карт Карно с выделением максимальных субкубов
- **Задача 9.10**: Доказательство теоремы Вильсона $(p-1)! \equiv -1 \pmod p$ через групповые свойства обратимых элементов $\mathbb{Z}_p^\times$
