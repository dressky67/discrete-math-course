# Задачи и решения к Главе 3. Комбинаторика

Содержит 10 задач по нарастанию сложности с подробными доказательствами и вычислениями:
- **Задача 3.1**: Подсчет сложности и количества паролей с ограничениями
- **Задача 3.2**: Анаграммы слова «МАТЕМАТИКА» (перестановки с повторениями)
- **Задача 3.3**: Формирование олимпиадной команды (сочетания с условием «хотя бы»)
- **Задача 3.4**: Метод перегородок: число целых решений $x_1+x_2+x_3+x_4=15$ в $\mathbb{Z}_{\ge 0}$ и $\mathbb{Z}_{\ge 1}$
- **Задача 3.5**: Комбинаторное доказательство тождества хоккейной клюшки $\sum_{i=k}^n \binom{i}{k} = \binom{n+1}{k+1}$
- **Задача 3.6**: Нахождение свободного члена в биномиальном разложении $(x\sqrt{x} + x^{-4})^{11}$
- **Задача 3.7**: Принцип включений-исключений для чисел, кратных 2, 3 и 5 до 1000
- **Задача 3.8**: Геометрический принцип Дирихле для 10 точек в равностороннем треугольнике
- **Задача 3.9**: Вычисление количества сюръекций через формулу включений-исключений
- **Задача 3.10**: Правильные скобочные последовательности и числа Каталана $C_n$
