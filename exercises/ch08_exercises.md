# Задачи и решения к Главе 8. Приложения: матрицы в графах, марковские цепи и графика

Содержит 10 задач по нарастанию сложности:
- **Задача 8.1**: Число замкнутых маршрутов длины 4 в полном графе $K_4$ через степень $A^4$
- **Задача 8.2**: Спектральное доказательство формулы Кэли $n^{n-2}$ через теорему Кирхгофа
- **Задача 8.3**: Доказательство стохастичности произведения и унитарности спектрального радиуса $\rho(P) = 1$
- **Задача 8.4**: Марковская цепь «Разорение игрока» с поглощающими состояниями
- **Задача 8.5**: Аналитический вывод стационарного распределения для матрицы $2 \times 2$ общего вида
- **Задача 8.6**: Матрица отражения плоскости относительно произвольной прямой в однородных координатах
- **Задача 8.7**: Доказательство равенства числа нулевых собственных значений лапласиана числу компонент связности
- **Задача 8.8**: Матрица перспективной проекции $4 \times 4$ в компьютерной графике
- **Задача 8.9**: Расчет вектора важности страниц Google PageRank для сети из 3 узлов
- **Задача 8.10**: Вариационный принцип Куранта-Фишера для второго собственного числа лапласиана (число Фидлера)
